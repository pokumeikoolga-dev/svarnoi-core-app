# ADR-0002: интерфейсы по роли поверх единой карточки заказа

- Статус: принято для проектирования
- Дата: 2026-07-26

## Контекст

Данные одного ремонта разбросаны по общим чатам, персональным диалогам, CRM и нескольким вкладкам Google Sheets. Менеджер вручную связывает сообщения мастера с договором и клиентом. При этом мастер обычно ведет одну машину и должен только фиксировать фото, этап и название найденной работы.

Попытка перенести все существующие таблицы и чаты в одинаковый интерфейс создаст новую перегруженную систему и не устранит лишние действия.

## Решение

1. Единственным операционным центром остается `ServiceOrder`.
2. Все роли работают с одними сущностями backend, но получают разные домашние экраны, действия и уровни видимости.
3. Домашний экран мастера показывает одну назначенную машину и только действия, необходимые в производстве.
4. Менеджер получает очередь действий, требующих решения, а не копию всех таблиц на одном экране.
5. Клиент получает только опубликованные и клиентские данные своего заказа.
6. Подрядчик в будущем получает доступ только к назначенной операции.
7. Внутренние заметки, клиентская стоимость, вознаграждение мастера и клиентские материалы имеют раздельные правила видимости.
8. Редкие административные функции не добавляются в основной рабочий путь мастера.

## Последствия

Преимущества:

- меньше риск отправить фото не тому клиенту;
- мастер не изучает CRM;
- менеджер получает контекст вместе с материалом;
- права доступа можно проверять на уровне роли и назначения;
- интерфейсы можно тестировать по одному, не запуская всю ERP.

Ограничения:

- потребуется явная матрица прав;
- одно и то же событие будет иметь разные представления;
- нужно поддержать назначение мастера и подъемника до включения мастерского интерфейса;
- общий компонент карточки нельзя превращать в общий доступ ко всем данным.

## Не решено этим ADR

- точные права каждой должности;
- временный доступ сотрудников;
- показ мастеру его вознаграждения;
- обязанности подсобных рабочих;
- интерфейс и юридическая модель подрядчика;
- окончательный состав клиентского кабинета.
